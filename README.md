# Full Stack .NET & Angular Dashboard Application

A high-performance enterprise dashboard application built with **.NET Core (.NET 8)** backend and **Angular (14+)** frontend, implementing clean architecture and secure RESTful APIs.

## 🚀 Tech Stack
* **Backend:** C#, .NET 8, ASP.NET Core MVC, Web API, Entity Framework Core, LINQ
* **Frontend:** Angular, TypeScript, HTML5, CSS3, Bootstrap
* **Database:** SQL Server (Advanced Indexing, Stored Procedures)
* **Architecture:** Clean Architecture, Repository Pattern, Dependency Injection

## 🛠️ Features
* **Secure Authentication:** Implemented JWT-based authentication and Role-Based Access Control (RBAC).
* **Real-time Data Processing:** Optimized SQL queries and stored procedures handling high-throughput transactions with zero latency.
* **Responsive UI:** Dynamic Single Page Application (SPA) design with smooth data rendering.
